Learn VALIS Workstation by doing

This tutorial teaches the full workflow from opening slides to validating registration quality and exporting outputs. It is designed for first-time users and lab handoff training.

What you will produce

Registered slides in output/<project_name>/registered/ plus summary.csv for quality metrics.

Time estimate

First run: 20-40 minutes including setup. Follow-up runs are usually 5-15 minutes depending on slide size.

Best entry setting

Start with VGG, Rigid + Non-rigid ON, Max image size = 2048, then tune only if needed.

1. Goals and Outcomes

By the end of this tutorial, you should be able to load a slide folder, run registration, review quality, and use post-registration tools (Blink, Quality Report, Warp Annotations, Save Options, Export ROI Crop, Merge Slides, and Session Bundle export).

2. Choose a Track

Pick one path based on your immediate outcome. You can complete Track 1 first and then branch into Tracks 2-4.

Track 1 - Fast Path

First successful registration

  • Open a known-good dataset
  • Run with baseline defaults
  • Verify output folder + summary CSV
Go to Track 1
Track 2 - QA

Quality validation and triage

  • Compare pre/post overlap quality
  • Use metrics to find outlier pairs
  • Decide rerun vs accept
Go to Track 2
Track 3 - ROI Workflow

Export aligned ROI crops

  • Set Save Options to WSI-compatible format
  • Export batch ROI crops from registered slides
  • Reopen outputs for animation or review
Go to Track 3
Track 4 - Multiplex Merge

Build merged multi-channel outputs

  • Map channels and assign colors
  • Tune overlap/normalization options
  • Export a collaboration-ready merged file
Go to Track 4
Recommendation: complete Tracks 1 and 2 before moving to ROI export or merge workflows.

3. Preflight Checklist

Check Recommendation Reason
Python version 3.9+ Matches package requirement in pyproject.toml.
RAM 16 GB minimum, 32 GB preferred Large WSI tiles can spike memory usage.
Disk free space At least 2-3x total input size Registered outputs and intermediates can be large.
GPU (optional) CUDA + PyTorch CUDA build Improves speed for SuperPoint/DISK/DeDoDe detectors.
Data prep: keep one case per folder and avoid mixing unrelated projects in the same input directory.

4. Install and Launch

Install in a virtual environment

git clone https://github.com/leonardolv/VALIS-GUI.git
cd VALIS-GUI
python -m venv .venv
.venv\Scripts\Activate.ps1   # Windows
pip install -r requirements.txt
pip install -e .

Run the app

python run_valis_workstation.py

Quick health checks

python -c "import valis, napari; print('Core packages OK')"
python -c "import torch; print(torch.cuda.is_available())"
If the app launches but viewer is missing: install napari with pip install "napari[all]", then restart.

5. UI Map

The interface uses a nested resizable splitter layout with five areas: Project, Slide Preview, central Napari viewer, Properties/Layers, and Status/Logs. All panels are separated by grip handles — dotted bars that highlight on hover — which you can drag to resize any panel.

The left sidebar has Project and Slide Preview tabs. The right sidebar has Properties and Layers tabs. The center holds the Napari viewer. The bottom bar shows progress and logs.

Layout keyboard shortcuts: Ctrl+O open folder, Ctrl+R run registration, Ctrl+B Blink, Ctrl+Shift+P performance stats, Ctrl+[ toggle left sidebar, Ctrl+] toggle right sidebar, Ctrl+Shift+L reset layout, Ctrl+Shift+C expand center panel.

6. First Registration (Hands-On)

Use the bundled example dataset to get a known-good first result:

examples/example_datasets/ihc/
  1. 1
    Open slide folder

    Use File -> Open Slide Folder, select examples/example_datasets/ihc.

    You should see slides listed in Project and thumbnails in Slide Preview.
  2. 2
    Confirm baseline settings

    Project name: IHC_Tutorial. Keep defaults: VGG, Similarity, Rigid + Non-rigid enabled, Max image size 2048.

    This setup is stable and representative for first run validation.
  3. 3
    Run registration

    Use File -> Run Registration or Ctrl+R. Confirm in the dialog.

    Progress moves to 100%; registered layers appear in viewer when complete.
  4. 4
    Inspect outputs on disk

    Open output/IHC_Tutorial and verify registered/ plus summary.csv.

    You now have reproducible artifacts for QA and reporting.
Cancellation: use the Cancel Registration button in Status dock only when needed. Partial outputs may remain.

9. Settings Cookbook + VALIS Function Map

Scenario Recommended settings Why
Fast smoke test Max image size 1024, non-rigid OFF Quick feedback on data quality and slide order.
Balanced production Max image size 2048-4096, non-rigid ON, VGG Reliable quality without excessive runtime.
Challenging fluorescence DISK/SuperPoint + GPU, masks ON, non-rigid ON Improves landmark robustness in difficult texture.
Highest precision Enable micro-registration, increase max sizes Refines local alignment at higher resolution.

10. Troubleshooting

Common issues

Issue Action
"Napari not available" Install/upgrade napari: pip install "napari[all]".
GPU checkbox disabled Install CUDA-capable PyTorch build and verify torch.cuda.is_available().
Registration too slow Reduce max image size, disable non-rigid for test runs, use ORB/BRISK for speed checks.
Out of memory Lower image size/pyramids, close other memory-heavy apps, use smaller batches.
Log file: detailed diagnostics are written to logs/valis_workstation.log.
