BioSlide v1.1.0 — Reference Manual

Complete technical reference for the Histology Slice Segmenter & Exporter. Covers every feature, dialog, keyboard shortcut, and configuration option in the application.

PySide6 / Qt 6 OpenCV OpenSlide PyVista / VTK Python 3.10+ CUDA Optional

1   Introduction

1.1   What Is BioSlide?

BioSlide is a professional desktop application for whole-slide image (WSI) analysis. Built for researchers, pathologists, and students working with digitized tissue specimens, it provides an end-to-end pipeline from slide import through segmentation, measurement, export, collage composition, camera animation, and 3D serial-section reconstruction.

1.2   Key Capabilities

WSI Viewing

Tiled viewer with multi-level pyramid zoom, pan, and LRU tile cache for .ndpi, .svs, .mrxs, .tif, .tiff

Segmentation

Automatic (Otsu, dual-space, adaptive) and manual (Magic Wand, Lasso, Eraser, Smart Brush) tissue detection

Export

PNG, JPEG, TIFF, PDF with feathered alpha, metadata embedding, batch queue with pause/resume/cancel

Collage

Drag-and-drop grid builder with templates, dividers, labels, and publication-ready PDF export

Animation

Camera keyframes, ROI system, easing curves, branding overlays, MP4/GIF/MOV/PNG sequence export

3D Reconstruction

Serial-section alignment (ORB/SIFT/AKAZE), textured stack rendering, fly-through video via PyVista/VTK

Measurements

Distance, area, perimeter, angle — calibrated in µm/mm via slide MPP metadata

Project System

.hssp JSON projects with autosave, crash recovery, undo/redo stack, and export profiles

2.2   Step-by-Step Setup

Step 1 — Clone the Repository 
git clone https://github.com/your-org/BioSlide.git
cd BioSlide
Step 2 — Create a Virtual Environment 
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
Step 3 — Install Dependencies 
pip install -r requirements.txt

Installs PySide6, OpenCV, OpenSlide bindings, PyVista, Pydantic, and all processing libraries.

Step 4 — Install OpenSlide (Windows) 
pip install openslide-bin

BioSlide automatically adds the OpenSlide DLL directory at startup via os.add_dll_directory(). On Linux/macOS, install OpenSlide via your system package manager.

Step 5 — (Optional) CUDA GPU Acceleration

To enable GPU-accelerated image operations, install a CUDA-enabled build of OpenCV:

pip install opencv-contrib-python-headless   # CPU-only (default)
# Build/install OpenCV with CUDA for GPU acceleration

BioSlide's GPUAccelerator auto-detects CUDA and falls back to CPU gracefully.

Step 6 — Launch BioSlide 
python main.py

A branded splash screen appears, followed by the Launcher Dashboard.

Note: BioSlide applies GPU runtime preferences (NVIDIA Optimus, AMD PowerXpress) automatically on Windows. Desktop OpenGL is preferred for Qt/VTK rendering via environment variables set at startup.

3   Quick Start

Go from raw slide to exported results in eight steps:

  1. Launch BioSlide — Run python main.py. The Launcher Dashboard appears with feature cards and recent projects.
  2. Create a project — Click New Project or press Ctrl+N. Choose a project name and save location.
  3. Import slides — Click Import Slides or press Ctrl+I. Select .ndpi, .svs, .mrxs, or .tif files.
  4. Preview — Open the Preview tab. Pan (click-drag), zoom (scroll wheel — centers at cursor), switch between single and grid view.
  5. Segment — Switch to the Segmentation tab. Click Auto Segment for automatic tissue detection, or use manual tools (Magic Wand, Lasso, Eraser).
  6. Refine — Right-click a slice and choose Refine Segmentation for interactive GrabCut-based boundary refinement. Merge or split slices as needed.
  7. Measure — Open the Measurement Panel to draw rulers, measure area, perimeter, or angles on segmented tissue.
  8. Export — Press Ctrl+E or click Export. Choose a format, select an export profile, and set the output directory.
Tip: Save your project frequently with Ctrl+S. Autosave runs every 5 minutes by default. After a crash, BioSlide offers to restore your last autosaved state.

12   Segmentation Tools — In Depth

12.1   Magic Wand W

Flood-fill region growing from a clicked seed point. Expands to neighboring pixels within the specified tolerance (0–255) of the seed color. Tolerance slider in the Property Panel. Creates a new slice mask from the filled region. Best for well-defined tissue regions with consistent staining.

12.2   Lasso Tool L

Freehand polygon selection. Click and drag to trace the tissue boundary. Release to auto-close the polygon and create a mask.

12.3   Eraser Tool E

Three modes for removing parts of existing masks:

  • Brush — Click and drag to erase with a circular brush
  • Path — Draw a freehand line to erase along its path
  • Polygon — Enclose a region to erase everything inside

12.4   Merge / Split

  • Merge (Ctrl+M) — Select 2+ masks and combine via OR union
  • Split (Ctrl+Shift+S) — Separate a single mask into individual connected components

12.5   Smart Brush (Advanced)

Gradient-guided circular brush that follows tissue edges while painting. Part of the advanced segmentation toolkit.

12.6   Edge-Aware Refiner (Advanced)

Contour smoothing via morphological operations. Cleans jagged mask boundaries while preserving overall shape.

12.7   Threshold Selector (Advanced)

Range-based pixel intensity selector. Set min/max intensity values to create masks from specific staining intensities.

12.8   Undo / Redo

All segmentation operations are recorded in a command stack (Command Pattern via CommandHistory):

  • Create, Edit, Merge, Split, and Delete mask commands
  • Ctrl+Z to undo, Ctrl+Y to redo
  • Signal-based notifications for automatic UI updates

13   Segmentation Refinement

A PowerPoint-style “Remove Background” interactive tool powered by OpenCV’s GrabCut algorithm.

13.1   How It Works

  1. Right-click a segmented slice and select Refine Segmentation
  2. The refinement dialog shows the slice with the current mask overlay
  3. Use Mark Areas to Keep to stroke over tissue regions
  4. Use Mark Areas to Remove to stroke over background regions
  5. GrabCut iteratively refines the mask boundary based on your strokes
  6. Real-time mask updates with edge-aware propagation
  7. Click Apply to accept or Cancel to discard

13.2   Key Features

  • Non-destructive editing with conflict resolution
  • Visual feedback showing foreground/background stroke regions
  • Multiple iterations of keep/remove strokes for progressive refinement
  • Edge-aware propagation respects tissue boundaries
Tip: Start with broad strokes on clearly wrong regions. GrabCut propagates corrections to similar areas automatically.

If the source WSI provides microns-per-pixel (MPP) metadata, all measurements are automatically calibrated to physical units. Otherwise, measurements are in pixel units.

16   Batch Processing

16.1   Batch Export Queue

The Batch Queue Dialog manages multi-slide export with:

  • Per-job progress bars showing completion percentage
  • Pause — Temporarily halt processing; resumes exactly where stopped
  • Resume — Continue paused export
  • Cancel — Stop the entire batch
  • Error display for failed jobs with detailed messages

Runs in a dedicated QThread (BatchExportWorker) with throttled progress signals.

16.2   Batch Segmentation

Via Segmentation → Batch Segment All: applies automatic segmentation to all loaded slides sequentially.

16.3   Batch Lobe Processing

Specialized workflow for brain tissue: lobe merging and cross-slide consistency tools via the Lobe Merge Dialog.

17   Project Management

17.1   .hssp Project Files

Projects are saved as .hssp files (JSON format, version 1.1.0). Contents:

  • Slide list with file paths and metadata
  • Segmentation masks (contour data)
  • Measurements and statistics
  • Export profile settings
  • Animation keyframes and ROI definitions
  • Version tracking for backward compatibility with migration/backfill for legacy files

17.2   Autosave

The AutosaveService provides automatic periodic saving:

  • Configurable interval (default: 5 minutes)
  • Dirty flag tracking — only saves when changes exist
  • Saves to a recovery file alongside the project

17.3   Crash Recovery

  1. On launch after a crash, the application checks for a recovery file
  2. If found, offers to restore the last autosaved state
  3. User can accept (load recovery) or decline (start fresh)
  4. Recovery file is cleared after successful load

17.4   Recent Projects

Tracked in QSettings; displayed in the Launcher Dashboard and File → Recent Projects menu.

17.5   Sequential Slice Numbering

The SequentialNumberer maintains consistent slice IDs:

  • Global and per-slide sequential numbering
  • Automatic renumbering after insertions or deletions
  • Range-based renumbering for bulk edits

17.6   Workflow Service

Guided workflow definitions (e.g., Extract → Segment → Export) with step-by-step execution, timing, status tracking, and JSONL run logs for provenance.

18   GPU Acceleration

BioSlide includes a GPUAccelerator singleton that detects CUDA availability and provides GPU-accelerated operations with automatic CPU fallback.

18.1   Detection

  • Checks for CUDA-enabled OpenCV build at startup
  • Detects system GPU adapters via wmic (Windows) or lspci (Linux)
  • Reports dedicated GPU name and VRAM information
  • GPU status shown in the status bar and logged at startup

18.2   Accelerated Operations

OperationGPU MethodCPU Fallback
Image resizeresize_gpu()cv2.resize()
Color conversioncvt_color_gpu()cv2.cvtColor()
Thresholdingthreshold_gpu()cv2.threshold()
Filteringapply_filter_gpu()cv2.filter2D()

18.3   GPU Preferences

On Windows, startup hints prefer the dedicated GPU:

  • NvOptimusEnablement = 1 for NVIDIA Optimus laptops
  • AmdPowerXpressRequestHighPerformance = 1 for AMD switchable graphics
  • Desktop OpenGL preferred over ANGLE for Qt/VTK rendering
Note: GPU acceleration is optional. All operations have CPU fallbacks. The application works identically (just slower for large images) without a GPU.

26   FAQ

Can BioSlide open proprietary scanner formats?

Yes. BioSlide uses OpenSlide for .ndpi (Hamamatsu), .svs (Aperio/Leica), and .mrxs (3DHISTECH). Standard TIFF pyramids use tifffile.

Does BioSlide require a GPU?

No. GPU acceleration is optional. All features work on CPU with automatic fallback.

Can I use BioSlide on macOS or Linux?

BioSlide is developed and tested on Windows. PySide6 and core libraries are cross-platform, so it may work on other systems with appropriate OpenSlide installation, but this is not officially supported.

How large can slide files be?

BioSlide handles slides of any size via tiled loading. Only visible tiles are in memory with an LRU cache. Multi-gigapixel slides are supported.

Is there a plugin system?

A plugin architecture is under development. The PluginService provides registration hooks but plugin loading/execution is not yet functional. This will be expanded in a future release.

Can I export measurements to Excel?

Statistics can be exported as CSV via the Statistics tab. CSV files open directly in Excel, Google Sheets, and pandas. JSON sidecar files also contain per-slice data.

What is AI-Assisted segmentation?

This is a planned feature. The current implementation uses Otsu thresholding as a placeholder. A trained ML model for histology tissue detection will be integrated in a future release.

How do I recover from a crash?

BioSlide’s autosave system saves every 5 minutes by default. After a crash, a recovery dialog offers to restore your last autosaved state.
